# 模块 0｜十分钟跑起你的第一个 Agent

大家好，这一章我们只做一件事：十分钟内让 Pi Agent 跑起来并说出第一句话。  
核心目标不是“写很多代码”，而是先建立最小闭环：创建 session、订阅流式输出、发出 prompt。你会看到，一旦最小闭环跑通，后面所有复杂能力都只是往这个闭环里加模块。  

接下来我们会做三步。第一步，跑 `00-minimal-agent.ts`，确认你的环境、依赖和 session 都正常。第二步，跑 `01-model-runtime.ts`，把模型管理接进来，理解 `ModelRuntime` 和“可用模型”的概念。第三步，跑 `02-custom-provider.ts`，体验通过 `models.json` 接入自定义 provider。  

这一章我重点强调一个工程底线：密钥不要写进代码。我们统一用 `.env` 或本地配置文件管理。  
到这里，你应该已经有了一个安全、可复用、可扩展的 Agent 起步模板。
