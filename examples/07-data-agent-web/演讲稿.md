# 模块 7｜DataAgent 第二阶段：Web 与可视化

这一章我们把同一套 DataAgent 核心能力搬到 Web。  
重点不是“重写一遍”，而是复用 core：同样的数据适配器、同样的安全层、同样的证据链。

推荐你按这个结构录：  
先讲架构：React/Vite 前端 + Node.js API/SSE 后端。  
再讲事件流：前端通过 SSE 看到 message、tool、turn 的实时过程。  
最后讲可视化与归因：Agent 通过受限协议声明图表意图，前端用 shadcn Chart/Recharts 渲染；图表和描述性贡献归因都必须绑定 result id、SQL、数据源和截断状态。

请重点强调：  
可视化不是“好看”，而是分析证据的一部分。  
如果图表不能追溯到查询结果，它就不应该进入结论和报告。  
这一章收官后，观众会看到一个可演示、可迭代、可产品化的 DataAgent Web MVP。

## 现场演示

在仓库根目录准备 Pi 模型凭据，然后启动：

```bash
pnpm install
pnpm example:data-agent-web
```

浏览器打开 `http://127.0.0.1:4317`，上传不超过 25 MB 的 SQLite、CSV、TSV、JSON、JSONL 或 NDJSON 文件。

建议按以下顺序演示：

1. 上传数据，查看左侧 Catalog 与字段类型。
2. 提问“这个数据集包含什么”，观察 Profile 和 Query 工具轨迹。
3. 提问“按一个合适的维度聚合指标并画图”，展示受限图表协议。
4. 在证据检查器中切换表格、图表和 SQL，核对 result id、来源及截断状态。
5. 生成过程中点击停止，再刷新页面验证 SSE 重连。

服务仅监听本机地址。上传文件保存在系统临时目录，替换数据集或关闭服务时会自动删除。
