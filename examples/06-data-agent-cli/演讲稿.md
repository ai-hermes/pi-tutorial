# 模块 6｜DataAgent 第一阶段：CLI/TUI 版本

从这一章开始，我们进入综合实战：构建一个可用的数据分析 Agent。  
第一阶段目标是 CLI/TUI 版本，优先把核心能力跑通，再谈界面包装。

你可以按这条主线讲：  
第一步，接入 CSV、DuckDB/SQLite、PostgreSQL。  
第二步，统一数据源适配器接口，保证 catalog、schema、profile、query 行为一致。  
第三步，落实只读安全边界：SQL 校验、超时、行数限制、错误分类。  
第四步，让 Agent 的结论绑定证据：数据源、SQL、结果截断状态。

这一章最重要的一句话是：  
DataAgent 的价值不是“会写 SQL”，而是“能给出可追溯、可复现的分析结论”。
