# 彩蛋课｜用个人照片生成倒挂金钩视频

这节课用一个具有视觉冲击力的案例展示 Pi 的可扩展性：

> 用户上传一张本人照片，Agent 自动检查素材、生成足球场景提示词、调用图像/视频生成工具，并输出一段原创的倒挂金钩短视频。

## 学习目标

- 理解 Pi 如何编排图片分析、提示词生成和视频生成工具。
- 学会把第三方图像/视频 API 封装为 Pi Tool。
- 学会处理异步任务、进度轮询、失败重试和产物下载。
- 理解真人照片使用中的授权、隐私、误导和内容标识问题。

## 推荐演示规格

- 输入：一张清晰、正面或半身的本人照片。
- 输出：5～8 秒、9:16 竖屏、原创体育场景短视频。
- 动作：助跑、腾空、倒挂金钩、足球入网、庆祝。
- 风格：电影感体育广告，不复刻真实球员、真实比赛或赛事转播画面。
- 标识：成片保留“AI Generated”提示。

## Agent Pipeline

```text
个人照片
  → 图片质量与授权检查
  → 人物特征描述
  → 足球场景关键帧生成
  → 用户确认人物一致性
  → 图生视频
  → 任务轮询与失败重试
  → 下载视频并生成分享文案
```
