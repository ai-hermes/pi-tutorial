# Pi Chat Web 品牌与界面资产说明

## 来源

- 产品事实与功能来源：本仓库 `README.md`、前端组件和共享类型。
- 视觉资产来源：Pi 官网 `https://pi.dev/` 的官方像素 Pi 标识与 Favicon、Geist/Geist Mono 字体与 Lucide 图标。
- 本项目是本地示例应用，没有独立公开品牌官网或外部素材包；不引入第三方产品图片。

## 标识

- 名称：Pi Chat
- 描述：Agent workbench / 本地 Agent 工作台
- 主标识：使用 Pi 官网 `logo-auto.svg` 的官方像素 Pi glyph；不再使用早期的实心三角形占位标识。
- Favicon：逐路径复用 Pi 官网 `favicon.svg`，本地固化在 `public/favicon.svg`，避免运行时依赖外网。
- 图标：继续使用已有 Lucide 线性图标；图标只表达动作和状态，不作标题装饰。

## 字体

- 界面与正文：Geist Variable。
- 代码、模型标识、工具名和短状态：Geist Mono Variable。
- 不额外加载远程字体，保证本地演示和离线构建稳定。

## 色彩原则

- 色彩必须服务于语义：运行/连接、成功、失败、警告、选中。
- 每个方向最多使用一个主要强调色和一组语义状态色。
- 安全警告只保留一个持续可访问入口，不用大面积红色占据侧栏与输入区。
- 禁止通用紫色渐变、深蓝霓虹 glow 和无语义的彩色卡片。

## 必含产品信息

- 会话历史、当前会话、模型与 thinking、连接状态。
- 用户消息、Pi 回复、工具调用与输出。
- 图片、Steer、Follow-up、停止/发送。
- Harness 检查器、上下文与设置入口。
- 「本机可信环境，Bash 未隔离」安全提示。

## 禁区

- 不把 Pi Chat 伪装成云端多租户产品。
- 不承诺沙箱、安全审批或远程协作等现有代码没有的能力。
- 不使用装饰性人物插画、虚构统计、营销口号或无来源品牌 Logo。
- 不删除任何现有核心能力，只允许在响应式布局中收纳次要控制。
