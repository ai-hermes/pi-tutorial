# 模块 9｜Pi Chat：把 Agent Harness 带到 Web

这一章不是再做一个普通聊天框，而是展示 ChatGPT 风格产品背后的 Agent harness。

首先看多会话与恢复。左侧每个对话都对应一个 Pi JSONL session，服务重启后仍能恢复模型、消息、工具结果和压缩摘要。服务端 runtime 并不需要永久常驻：它按需加载，空闲后释放。

然后观察 Agent loop。发送一个需要修改文件的任务，界面会实时展示 assistant 文本、工具参数、Bash 输出和 edit patch。运行中发送 `Steer` 会改变当前任务方向，发送 `排队` 则会在当前任务完成后继续。

接着打开 Harness 检查器。这里能看到自动重试、上下文压缩、队列、token、费用和 context usage。切换模型与 thinking level 也是直接操作同一个 Pi session，而不是前端假状态。

最后演示图片输入和会话分支。编辑历史消息时，Pi 从对应 entry 创建新的 session 分支，同时保留原历史。分支共享代码 workspace，因此观众也能理解：对话上下文分支与文件系统隔离是两个不同维度。

录制时必须强调安全边界：独立 cwd 不是 OS 沙箱。完整 Bash 工具只适合本机可信演示，不能直接暴露给不可信用户。
