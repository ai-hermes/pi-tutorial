# 彩蛋课｜用个人照片生成属于你的倒挂金钩视频

> 建议时长：10～15 分钟  
> 演示形式：真人出镜开场 + 屏幕录制 + 最终视频展示

## 片头：先展示结果

大家好，今天我们来做一节彩蛋课。

我先不给大家看代码，先看最终效果：我只提供了一张自己的照片，Pi 就自动完成了素材检查、场景设计、提示词生成和视频任务编排，最后生成了一段属于我的倒挂金钩视频。

这里需要先说明：我们不会使用真实世界杯比赛录像，也不会复刻某一位真实球员。我们要生成的是一个原创足球场景，只借用“世界级足球决赛氛围”和“倒挂金钩”这个动作概念。

这节课真正想展示的，不只是 AI 能生成视频，而是 Pi 如何把多个能力组合成一条完整工作流。

## 第一部分：为什么要让 Agent 编排

如果我们手动完成这个任务，通常需要做很多事情：

第一，检查照片是否清晰，人物是不是完整。  
第二，编写图片生成提示词，把人物放进足球场景。  
第三，生成动作开始前的关键帧。  
第四，把关键帧交给视频模型，描述助跑、腾空、射门和入网。  
第五，等待异步任务完成，并处理生成失败。  
第六，下载视频，保存生成参数，再输出分享文案。

这些步骤并不适合全部写死在一个脚本里。我们更希望 Agent 根据中间结果做判断：照片不合格时提醒用户更换；人物一致性不好时重新生成关键帧；视频任务失败时根据错误调整参数。

这就是 Agent 编排的价值。

## 第二部分：准备个人照片

现在我准备一张自己的照片。

建议照片满足几个条件：

- 人脸清晰，没有严重遮挡。
- 最好是正面或四十五度角。
- 光线均匀，不要过曝。
- 背景尽量简单。
- 必须是本人照片，或者已经获得照片中人物的明确授权。

上传之后，Pi 先调用 `inspect_photo` 工具检查图片，而不是立即生成视频。

这个工具会返回图片尺寸、主体数量、人物可见范围和质量建议。  
如果照片中有多个人，或者人脸太小，Agent 就会停止流程，并告诉我应该如何重新准备素材。

## 第三部分：生成原创足球关键帧

照片通过检查后，Agent 会生成关键帧提示词。

这里有一个非常重要的技巧：不要直接要求视频模型“把这个人变成倒挂金钩”。  
更稳定的方式是先生成一个动作关键帧，再让视频模型围绕这个关键帧完成运动。

关键帧可以这样描述：

“保留参考照片中的人物身份特征。原创夜间足球决赛场景，人物穿无品牌的红色球衣，在禁区内准备完成倒挂金钩。体育场灯光、观众虚化、电影感体育摄影、动态低机位、真实人体比例。”

大家注意，我没有写真实赛事名称、真实球队队服，也没有要求模仿某位球星。  
这样既能保留视觉冲击力，也能避免让生成结果看起来像真实比赛录像。

关键帧生成完成后，Pi 不会直接进入下一步，而是先让我确认人物是否像本人。  
这一步属于 human-in-the-loop：关键节点由用户确认，避免算力浪费，也避免生成错误内容继续向后传播。

## 第四部分：让关键帧动起来

确认关键帧后，Agent 调用 `generate_video` 工具。

视频提示词需要描述时间顺序，而不是只写一个动作名称。例如：

“镜头从低机位跟随运动员快速进入禁区。运动员转身起跳，身体向后腾空，完成流畅有力的倒挂金钩。足球高速飞向球门右上角并入网。球网产生明显形变，体育场灯光闪烁，观众欢呼。保持人物身份和球衣一致，动作符合人体结构，镜头稳定，时长六秒。”

这里我们还会明确负面约束：

“不要出现额外肢体、人物脸部变化、足球消失、球门变形、真实球队标志、电视台台标或赛事水印。”

工具调用后通常不会立即返回视频，而是返回一个任务 ID。  
Pi 接下来调用 `poll_task`，定期检查任务状态，并通过事件流告诉用户当前进度。

如果任务失败，我们不做静默重试。Agent 会读取明确的失败原因，再决定是降低分辨率、缩短时长，还是重新生成关键帧。

## 第五部分：展示最终产物

任务完成后，Agent 下载视频，并把视频文件、关键帧、最终提示词和任务参数放在同一个产物目录中。

现在我们来看最终效果。

这里可以播放生成的视频，然后切回终端展示 Agent 最后的总结：

- 使用了哪张照片。
- 生成了哪个关键帧。
- 视频采用了什么参数。
- 是否发生过重试。
- 最终文件保存在哪里。

这个过程很重要，因为可复现性不只适用于数据分析，也适用于内容生成。

## 第六部分：这个案例体现了 Pi 的什么能力

回过头看，这个彩蛋案例其实把前面课程的知识串起来了：

- 图片输入来自多模态能力。
- 素材检查和视频生成来自自定义 Tool。
- 任务状态通过 Agent 事件实时展示。
- 提示词和制作规则可以封装成 Skill。
- 不同视频供应商可以通过 Extension 或统一工具接口替换。
- 整个生成过程可以保存在 Session 中，方便恢复和复盘。

所以我们不是写了一个只能生成倒挂金钩的视频脚本，而是搭建了一套可以扩展到旅行短片、产品广告、数字人视频和创意内容生产的 Agent Pipeline。

## 安全与发布提示

在发布之前，请确认三件事：

第一，只使用本人照片，或者已经获得人物授权。  
第二，不要把生成内容描述成真实比赛录像或真实事件。  
第三，发布时保留“AI Generated”或同等含义的提示。

如果产品允许用户上传其他人的照片，还需要增加授权确认、内容审核、文件生命周期和删除机制。

## 结尾

这节彩蛋课到这里就完成了。

我们从一张个人照片出发，通过 Pi 编排图片理解、关键帧生成、图生视频、异步任务和产物管理，最终得到了一段原创的倒挂金钩短视频。

这就是 Pi 的灵活性：模型和供应商可以替换，工具可以增加，流程可以调整，但 Agent 的编排方式保持稳定。

下一步，我们会把这套工作流真正封装成可运行的 Pi Tool 和 Skill，让用户只需要上传照片并说一句话，就能完成整个制作过程。
