# 模块 1｜Agent 的心脏：工具调用闭环

这一章我们要回答一个关键问题：Agent 为什么不只是“聊天”？  
因为 Agent 会循环执行：思考、调用工具、读取结果、继续推理，直到任务完成。这就是 Agent Loop。

我们先跑 `00-observe-loop.ts`，现场看 `agent_start`、`turn_start`、`tool_execution_start/end` 这些事件，让你看到“内部发生了什么”。  
然后跑 `01-readonly-tools.ts`，只给 Agent 读权限，演示工具白名单如何限制行为边界。  
最后跑 `02-custom-tool.ts`，用 `defineTool` 给 Agent 增加一个结构化工具，让它学会“按规范调用能力”。

这一章的核心收获是：你不仅能使用 Agent，还能控制 Agent。  
你知道它每一步在做什么，也知道如何把它限制在你允许的范围内。
