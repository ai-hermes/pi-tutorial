# 模块 2｜上下文工程：让 Agent 不“失忆”

为什么同一个 Agent，有时候很聪明，有时候突然跑偏？  
答案通常不是模型不行，而是上下文没有被正确组织。

这一章我们先用 `00-system-prompt.ts` 演示如何通过 `DefaultResourceLoader` 给 Agent 设定稳定规则。  
你会看到，系统提示词不是“装饰语”，而是行为约束和输出风格的入口。后续我们还会把 AGENTS、skills、prompt templates 一起纳入上下文体系。  

这章录制时建议你反复强调一句话：上下文工程不是写长提示词，而是写清楚边界、目标和证据标准。  
当你把这些内容结构化，Agent 的稳定性会明显提高。
